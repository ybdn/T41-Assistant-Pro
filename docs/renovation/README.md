# Chantier de rénovation — T41 Assistant Pro

Dossier **temporaire** regroupant tous les documents du chantier de rénovation du projet. Une fois le chantier terminé (toutes les phases de `PLAN.md` exécutées), ce dossier pourra être archivé ou supprimé — la documentation pérenne vivra dans `docs/ARCHITECTURE.md`, `docs/CONVENTIONS.md` et `docs/adr/`.

## Contenu

| Document | Rôle |
|---|---|
| `AUDIT.md` | État des lieux : inventaire, métriques, dette, scores KISS par zone |
| `PLAN.md` | Plan de rénovation en 7 phases avec structure cible |
| `ETUDE-CONTRADICTOIRE.md` | Critique adversariale du plan et des issues — biais, risques, manques |
| `issues/` | 10 issues GitHub prêtes à copier-coller |

## Ordre de lecture conseillé

1. `AUDIT.md` — comprendre l'existant
2. `PLAN.md` — comprendre la cible et la trajectoire
3. `ETUDE-CONTRADICTOIRE.md` — challenger avant d'agir
4. `issues/` — exécuter
